# Mufliha Islamic Data Web Platform
An authentic, fast, mobile-first Islamic web feed providing Sahih Hadees, Daily Masnoon Duas, 7-Day Dual Salah Timetables, Interactive Quizzes, and Verified Sponsor promotions.

## Architecture
- `index.html`: Client rendering UI, CSS themes, and interactive modals.
- `content.js`: Centralized data store and feed arrays.
- `generator.html`: Syntax-safe post, quiz, and ad code publisher.
- `legal.html`: Bilingual policy center (English/Hindi).
- `sw.js` & `manifest.json`: Progressive Web App (PWA) engine.
